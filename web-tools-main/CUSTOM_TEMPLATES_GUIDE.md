# دليل القوالب المخصصة - Custom Templates Guide

## نظرة عامة | Overview

نظام القوالب المخصصة يتيح لك إنشاء تصاميم عروض وظيفية فريدة باستخدام تصاميم Figma مباشرة، دون الحاجة لكتابة كود برمجي.

The Custom Templates system allows you to create unique job offer designs using Figma designs directly, without writing code.

---

## الميزات الرئيسية | Key Features

✅ **استيراد من Figma** - الصق كود JSX مباشرة من Figma Dev Mode
✅ **تحويل تلقائي للأنماط** - تحويل inline styles إلى Tailwind CSS
✅ **رفع الأصول** - رفع الصور والأيقونات المخصصة
✅ **ربط البيانات** - ربط تلقائي بين التصميم وبيانات النموذج
✅ **معاينة حية** - معاينة التصميم مع البيانات الفعلية
✅ **تعديل الأبعاد** - ضبط المسافات والأحجام بدقة

---

## كيفية الاستخدام | How to Use

### الخطوة 1: إنشاء قالب جديد | Step 1: Create a New Template

1. انتقل إلى صفحة **القوالب المخصصة** (`/custom-templates`)
2. اضغط على **"إنشاء قالب جديد"**
3. أدخل اسم القالب ووصفه
4. الصق كود React JSX من Figma Dev Mode

**كيفية الحصول على الكود من Figma:**

```
1. افتح التصميم في Figma
2. فعّل وضع Dev Mode (Shift + D)
3. اختر العنصر/الإطار المطلوب
4. اختر "React" من القائمة
5. انسخ الكود كاملاً
6. الصقه في حقل "كود Figma"
```

### الخطوة 2: تحويل الأنماط | Step 2: Convert Styles

- **Tailwind CSS (موصى به):** يحول inline styles إلى Tailwind classes
- **Inline Styles:** يبقي الأنماط كما هي

النظام سيحول تلقائياً:
- Width & Height → `w-*`, `h-*`
- Colors → `bg-*`, `text-*`
- Flexbox → `flex`, `justify-*`, `items-*`
- Positions → `absolute`, `relative`
- Spacing → `gap-*`, `p-*`, `m-*`

### الخطوة 3: رفع الأصول | Step 3: Upload Assets

النظام سيكتشف تلقائياً:
- `<img src="https://placehold.co/...">` placeholders
- جميع الصور الخارجية

**نصائح:**
- استخدم PNG أو SVG للحصول على أفضل جودة
- خلفية شفافة للأيقونات
- حجم معقول (< 2MB لكل صورة)

### الخطوة 4: ربط البيانات | Step 4: Map Data Fields

النظام سيكتشف:
- **الأرقام** (رواتب، بدلات)
- **نصوص عربية** (أسماء، مسميات وظيفية)

**الحقول المتاحة للربط:**

| الحقل | الوصف | النوع |
|-------|-------|------|
| `formData.name` | اسم الموظف | نص |
| `formData.jobTitle` | المسمى الوظيفي (عربي) | نص |
| `formData.monthlySalary` | الراتب الشهري | رقم |
| `formData.basicSalary` | الراتب الأساسي | رقم |
| `formData.housingAllowance` | بدل السكن | رقم |
| `formData.transportAllowance` | بدل النقل | رقم |
| `formData.department` | القسم | نص |
| `formData.team` | الفريق | نص |
| `formData.directManager` | المدير المباشر | نص |

**خيارات:**
- **ربط بحقل** - يتغير حسب بيانات النموذج
- **نص مخصص** - نص ثابت لا يتغير

### الخطوة 5: المعاينة والحفظ | Step 5: Preview & Save

**أدوات المعاينة:**
- 🎯 **خطوط الإرشاد** - لعرض حدود الصفحة A4
- 🔍 **التكبير** - من 50% إلى 150%

**ضبط الأبعاد:**
- المسافة العلوية (0-300px)
- المسافة السفلية (0-300px)
- المسافة الجانبية (0-100px)
- حجم الخط (8-24pt)

## استخدام القالب في عرض وظيفي | Using Template in Job Offer

1. انتقل إلى **إنشاء عرض وظيفي** (`/job-offer`)
2. في قسم "المظهر 🎨"، اختر **"قالب مخصص 🎨"**
3. اختر القالب من القائمة المنسدلة
4. أكمل باقي بيانات النموذج
5. في المعاينة، سيظهر تصميمك مع البيانات الفعلية

---

## مثال عملي | Practical Example

لنفترض أنك تريد إنشاء صفحة "المزايا الوظيفية":

### 1. التصميم في Figma
```
- عنوان: "المزايا الوظيفية الإضافية"
- بطاقات المزايا (تدريب، سفر، تأمين، إلخ)
- جدول الراتب والبدلات
- توقيعات الموظف والمدير
```

### 2. الحصول على الكود
```jsx
<div style={{width: '100%', height: '100%', ...}}>
  <div>المزايا الوظيفية الإضافية</div>
  <div>17,500</div>  // سيتم ربطه بـ formData.monthlySalary
  ...
</div>
```

### 3. رفع الأصول
- أيقونة الطيران ✈️
- أيقونة التدريب 📚
- أيقونة التأمين الطبي 🏥
- أيقونة المرونة 💼

### 4. ربط البيانات
```
17,500 → formData.monthlySalary
8,203 → formData.basicSalary
2,051 → formData.housingAllowance
246 → formData.transportAllowance
```

### 5. النتيجة
PDF احترافي بتصميمك الخاص مع البيانات الديناميكية!

## حدود النظام | System Limitations

❌ **لا يدعم:**
- JavaScript interactivity (الأزرار، الأحداث)
- Animations (التحريكات)
- External API calls (استدعاءات API)
- Complex components (مكونات معقدة)

✅ **يدعم:**
- Static layouts (تخطيطات ثابتة)
- Images & Icons (صور وأيقونات)
- Dynamic text/numbers (نصوص/أرقام ديناميكية)
- Custom fonts (خطوط مخصصة)
- Print-ready designs (تصاميم جاهزة للطباعة)

## نصائح وأفضل الممارسات | Tips & Best Practices

### 🎨 التصميم في Figma

1. **استخدم إطار بأبعاد A4:**
   - Width: 210mm (595px في 72 DPI)
   - Height: 297mm (842px في 72 DPI)

2. **تجنب التصاميم شديدة التعقيد:**
   - استخدم Frames بدلاً من Groups
   - تجنب الكثير من التداخلات (nested layers)

3. **استخدم نظام ألوان واضح:**
   - استخدم الألوان المحددة مسبقاً (#F2EEE4, #54b974, إلخ)
   - تجنب الظلال والتدرجات المعقدة

### 💻 الكود

1. **قبل النسخ من Figma:**
   - تأكد من تسمية الطبقات بشكل واضح
   - استخدم Auto Layout للتخطيطات
   - جمّع العناصر المتشابهة في Components

2. **بعد اللصق:**
   - راجع الكود المحول
   - تأكد من وجود جميع العناصر
   - اختبر في المعاينة

### 📊 البيانات

1. **ربط الحقول:**
   - ابدأ بالحقول الأساسية (الاسم، الراتب)
   - استخدم "نص مخصص" للعناوين والنصوص الثابتة
   - تحقق من المعاينة بعد كل ربط

2. **الأرقام:**
   - سيتم تنسيق الأرقام تلقائياً (17,500)
   - استخدم formData fields للقيم الديناميكية
   - استخدم نص مخصص للعناوين ("ريال سنوياً")

## استكشاف الأخطاء | Troubleshooting

### المشكلة: الكود لا يتحول بشكل صحيح

**الحل:**
- تأكد من نسخ الكود كاملاً من Figma
- جرّب "Inline Styles" بدلاً من Tailwind
- تحقق من عدم وجود أخطاء في console

### المشكلة: الصور لا تظهر

**الحل:**
- تأكد من رفع جميع الأصول
- تحقق من حجم الصور (< 2MB)
- استخدم صيغ مدعومة (PNG, JPG, SVG)

### المشكلة: البيانات لا تظهر في المعاينة

**الحل:**
- تحقق من ربط الحقول في خطوة "ربط البيانات"
- تأكد من اختيار الحقل الصحيح
- راجع المعاينة بعد كل تغيير

### المشكلة: الأبعاد غير صحيحة في PDF

**الحل:**
- استخدم أدوات "ضبط الأبعاد" في المعاينة
- تحقق من إعدادات الطباعة (A4, margins: 0)
- اختبر مع "خطوط الإرشاد" مفعّلة
